# קטלוג ספרי אמא ז״ל - מערכת חלוקה למשפחה 📚

מערכת אינטראקטיבית, מהירה ופשוטה להצגת תמונות של ארגזי הספרים, שמות הספרים שזוהו בתוכם, ואפשרות לכל בן משפחה לסמן אילו ספרים הוא מעוניין לקבל.
כולל אפשרות עריכה, ניהול סטים שלמים, זום מלא לתמונות, ריכוז בקשות בטבלה, ייצוא לאקסל, והדפסה.

---

## 🗂️ סדר הקבצים והתיקיות (מה שייך למה):

```text
📁 ספרים אמא/
│
├── 🌐 קבצי האתר (אלו הקבצים הדרושים להעלאה לאינטרנט / GitHub Pages):
│   ├── index.html            <- דף האתר הראשי (פשוט לחץ עליו פעמיים להרצה במחשב)
│   ├── style.css             <- עיצוב האתר (עברית נקייה ורספונסיבית לכל טלפון ומחשב)
│   ├── app.js                <- כל לוגיקת האתר (חיפוש, זום, סינון, רישום, עריכה, ייצוא)
│   ├── books_data.js         <- מאגר המידע של כל 60 הארגזים ו-800 הספרים
│   └── web_images/           <- תיקיית התמונות הממוטבות (10MB בלבד! נטענות ברגע בנייד)
│
├── ☁️ חיבור לענן:
│   └── google_apps_script.js <- קוד קצר להדבקה ב-Google Sheets לסנכרון בזמן אמת
│
├── 📦 גיבויים וקבצים כבדים:
│   ├── original_photos/      <- 60 התמונות המקוריות הכבדות ברזולוציה המלאה (190MB)
│   └── scripts_and_data/     <- קובצי הפענוח הגולמיים וסקריפטי הבנייה והאופטימיזציה
│
└── 📄 README.md              <- מסמך הסבר זה
```

## 🔍 תכונות חדשות באתר:
1. **🔍 הגדלת תמונה וזום מלא (Lightbox):**
   - לחיצה על תמונת ארגז פותחת צופה מסך מלא.
   - כפתורי **➕ הגדל** ו-**➖ הקטן** (או גלגלת העכבר).
   - כפתור **🔄 סובב** (שימושי במיוחד לתמונות שצולמו לרוחב).
   - גרירה של התמונה בעכבר כשהיא מוגדלת.
   - כפתור **↗ פתח בחלון חדש** לתמונה המקורית.
2. **✏️ מצב עריכה (נפתח בראש הדף):**
   - לחיצה על **"✏️ מצב עריכה"** מאפשרת לערוך כל ספר (שם, מחבר), למחוק ספר שגוי (🗑️), ולערוך את תיאור הארגז.
   - כפתור **"💾 הורד קובץ נתונים מעודכן"** מאפשר להוריד בלחיצה אחת את `books_data.js` עם כל התיקונים שלך.
3. **📦 ניהול סטים שלמים (רמב"ם פרנקל, משנה ברורה וכו'):**
   - סטים מזוהים אוטומטית ומסומנים בתגית בולטת **"📦 סט שלם"** עם כפתור *"אני רוצה את כל הסט"*, כדי למנוע פירוק כרכים בודדים.
   - בכל עריכת ספר ניתן לסמן או לבטל את הגדרת הסט בצ'קבוקס פשוט.

## 🚀 איך להפעיל מיד במחשב:
פשוט לחץ לחיצה כפולה על **`index.html`** בדפדפן (Chrome / Edge / Firefox).

## 🌐 העלאה ל-GitHub Pages:
1. פתח טרמינל בתיקייה זו.
2. בצע:
   ```bash
   git add index.html style.css app.js books_data.js web_images/ google_apps_script.js README.md
   git commit -m "Upload ima-books website"
   git push -u origin main
   ```
   *(שים לב: תיקיית `original_photos` כבדה ואינה נדרשת כדי שהאתר יפעל במהירות, אך ניתן לכלול אותה כגיבוי).*
3. בהגדרות המאגר ב-GitHub: היכנס ל-**Settings** ⬅️ **Pages** ⬅️ תחת **Branch** בחר **main** ולחץ **Save**.
4. האתר יהיה זמין בכתובת: `https://nafeinot-cloud.github.io/ima-books/`
